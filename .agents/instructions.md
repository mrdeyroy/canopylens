# CanopyLens Instructions

## Project Overview
- **Project Name:** CanopyLens
- **Purpose:** Analyze high-resolution forest imagery to detect individual tree crowns and estimate canopy area.
- **Context:** Solo hiring hackathon project.

## Core Rules & Principles
- **Prioritize working product:** Prioritize a working product over unnecessary complexity.
- **Scientific honesty:** Do not invent measurements or claim accuracy that has not been validated. Clearly expose model limitations.
- **Model selection:** Prefer existing pretrained models over training a new model within the hackathon deadline.
- **Explainability:** Keep the architecture simple and explainable.
- **Feature focus:** Every major feature should directly support:
  - Tree detection
  - Tree counting
  - Canopy-area estimation
  - Usability
  - Honest reporting
- **No bloat:** Do not add unrelated SaaS features. Do not over-engineer.
- **Context awareness:** Before making major architectural decisions, inspect the existing project files.
- **Minimal dependencies:** Keep dependencies minimal.
- **Regression prevention:** All future phases must preserve working functionality from earlier phases.
